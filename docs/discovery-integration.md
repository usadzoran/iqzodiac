# IQZodiac: إعداد ملف الاكتشاف وMatch

## تدفق التسجيل

بعد إنشاء الحساب، يوجّه التسجيل المستخدم المصادق عليه إلى `discovery-profile.html`. تُحمّل الصفحة ملف `discovery_profiles` وإجابات `discovery_answers` الحالية، ثم تستأنف من أول حقل ناقص فقط. لا تمسح الإجابات المحفوظة ولا تنشئ ملفًا ثانيًا.

يُحفظ تاريخ الميلاد من بيانات التسجيل/ملف المستخدم، وتجمع صفحة الإعداد إجابات الشخصية والاهتمامات وعنصر الشخصية. يُحسب البرج من تاريخ الميلاد. تستخدم إجابات الاستبيان إصدار التخزين `discover-v2` ومعرّفات `q1` إلى `q17` و`interests`؛ يجب إبقاء الإصدار ومفاتيح upsert متوافقة عند تعديل الأسئلة.

يُحدّث ملف واحد لكل مستخدم عبر `user_id`، وتُحدّث الإجابات وفق مفتاح التعارض `user_id,questionnaire_version,question_id`. لا تُنشئ بيانات اختبار أو حسابات أعضاء تجريبية.

## تدفق Match

يتحقق `match.js` من جلسة Supabase ويقرأ لقطة ملف الاكتشاف عبر محول البيانات الحالي. إذا كان الملف مكتملًا وقابلًا للاكتشاف، يعرض Match الأعضاء الحقيقيين المؤهلين مباشرة. إذا كانت هناك معلومات ناقصة، يوضح الحقول المطلوبة ويقدم رابط استكمال إلى `discovery-profile.html`. تبقى الإعجابات والتخطي والتطابق المتبادل ضمن التدفق الحالي.

## الجداول

يعتمد الإعداد على `discovery_profiles` و`discovery_answers` الموجودة. لا يحذف هذا التدفق جداول أو سجلات الملف أو الإجابات.
